# Venue logos

Drop each venue logo here. The ticker on the home page picks them up automatically.

**File name = slug + extension** (PNG with transparent background works best).

Run `python scripts/process-all-venue-logos.py` after adding `-ig.jpg` downloads or updating sources.

Tips:
- Prefer **white or light** logos on transparent PNG — they render cleanly on the dark strip.
- Keep height around **80–120 px**; the site scales them down.
- If a logo is missing, the venue name is shown as text until you add the file.
